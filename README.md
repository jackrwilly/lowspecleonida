# LowSpecLeonida

Source for https://lowspecleonida.com: budget PC guides for GTA 6 on PC.

- `build/build.py`: generates the whole site into `site/`
- `build/style.css`: site styles
- `site/`: the published site (Netlify publishes this folder)
- `CHANGELOG.md`: every update, newest first

To rebuild: `python3 build/build.py`
